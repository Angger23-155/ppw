Klasifikasi Berita Detik.com (SPORT vs FINANCE) dengan Skip-gram dan TF-IDF + Naive Bayes#

  1. Muat kembali dataset berita hasil crawling (data_berita_sport_finance.csv).

  2. Lakukan preprocessing teks dengan dua jalur:

    • Jalur Skip-gram: cleansing, case folding, dan tokenisasi, tanpa stopword removal dan tanpa stemming.

    • Jalur TF-IDF: cleansing, case folding, stopword removal, dan stemming.

  3. Bangun representasi vektor kata dengan Word2Vec metode Skip-gram (sg=1), lalu ubah setiap berita menjadi satu vektor dokumen (rata-rata vektor kata penyusunnya).

  4. Lakukan klasifikasi berita dengan Naive Bayes pada dua representasi: Skip-gram (GaussianNB) dan TF-IDF (MultinomialNB).

  5. Evaluasi model (accuracy, precision, recall, F1-score, confusion matrix, dan cross-validation).

  6. Bandingkan hasilnya dengan representasi TF-IDF dan PCA dari tugas sebelumnya.

  7. Simpan kedua model (model_skipgram_nb.pkl dan model_tfidf_nb.pkl) untuk aplikasi Streamlit app.py, yang dapat memilih salah satu metode.

Mengapa berbeda? Skip-gram belajar dari urutan kata dan konteks sekitar kata, sehingga kata dibiarkan seperti pada teks aslinya (tanpa stopword removal dan stemming) agar jendela konteksnya tetap utuh. TF-IDF justru menghitung bobot kata, sehingga kata umum dibuang dan kata diubah ke bentuk dasarnya supaya bobot satu kata tidak terpecah ke beberapa bentuk (“menang”, “kemenangan”, “memenangkan”).

File tfidf_berita.csv dan pca_berita.csv hanya menyimpan angka, sedangkan teks bersihnya tidak tersimpan. Jadi preprocessing dijalankan ulang di sini dari data mentah.

Penjelasan cell berikutnya: Cell ini menyiapkan satu fungsi bersihkan_teks() dengan dua saklar, hapus_stopword dan stemming, serta dua fungsi pembungkus:

  • praproses_tfidf(): kedua saklar menyala (langkah lengkap, sama seperti preprocessing.ipynb).

  • praproses_skipgram(): kedua saklar mati.

Cell ditutup dengan uji pada satu kalimat agar perbedaan hasil kedua jalur langsung terlihat.

}
stop_words_final |= custom_stopwords
stemmer = StemmerFactory().create_stemmer()

def bersihkan_teks(text, hapus_stopword=True, stemming=True):
    if not isinstance(text, str):
        return ""
    text = re.sub(r'[^a-zA-Z\s]', ' ', text).lower()   # cleansing + case folding
    text = re.sub(r'\s+', ' ', text).strip()
    words = [w for w in text.split() if len(w) > 1]      # tokenisasi, buang token 1 huruf
    if hapus_stopword:                                   # stopword removal
        words = [w for w in words if w not in stop_words_final]
    if stemming:                                         # stemming
        words = [stemmer.stem(w) for w in words]
    return ' '.join(words)

def praproses_tfidf(text):
    return bersihkan_teks(text, hapus_stopword=True, stemming=True)

def praproses_skipgram(text):
    return bersihkan_teks(text, hapus_stopword=False, stemming=False)

# Uji kedua jalur pada satu contoh kalimat

4. Melatih Model Skip-gram (Word2Vec)#

Cara kerja Skip-gram: Model mengambil satu kata target lalu belajar memprediksi kata-kata konteks di sekitarnya (window). Kata yang sering berada di konteks serupa akan mendapat vektor yang berdekatan. Misalnya kata bertema bursa saham akan berdekatan satu sama lain, dan terpisah dari kata bertema sepak bola.

5. Membuat Vektor Dokumen#

Skip-gram menghasilkan vektor untuk kata, sedangkan klasifikasi membutuhkan satu vektor untuk setiap berita. Cara paling sederhana adalah rata-rata (mean pooling) dari semua vektor kata dalam berita tersebut:

\[\vec{d} = \frac{1}{n}\sum_{i=1}^{n}\vec{w_i}\]

Penjelasan cell berikutnya: Fungsi doc_vector() mengambil vektor tiap kata yang ada di vocabulary, lalu merata-ratakannya. Kata yang tidak ada di vocabulary (mis. muncul hanya sekali) dilewati. Jika tidak ada satu kata pun yang dikenal, dikembalikan vektor nol. Hasil akhirnya adalah matriks X berukuran (jumlah berita, 100) dan larik label y.

def doc_vector(tokens, wv):
    vecs = [wv[t] for t in tokens if t in wv]
    if not vecs:
        return np.zeros(wv.vector_size)
    return np.mean(vecs, axis=0)

X = np.vstack([doc_vector(tokens, model_sg.wv) for tokens in tokenized])

print("Bentuk X (dokumen x dimensi):", X.shape)
print("Bentuk y                    :", y.shape)
print("Nilai minimum di X          :", round(X.min(), 4), "(ada nilai negatif)")

7. Klasifikasi dengan Naive Bayes#

Pilihan varian Naive Bayes. Naive Bayes menerapkan Teorema Bayes dengan asumsi setiap fitur saling bebas:

\[P(C \mid x_1,\dots,x_n) \propto P(C)\prod_{i=1}^{n} P(x_i \mid C)\]

Vektor Skip-gram berisi bilangan kontinu dan bisa negatif. Konsekuensinya:

  • GaussianNB (dipakai sebagai model utama): cocok untuk fitur kontinu karena mengasumsikan tiap fitur berdistribusi normal di setiap kelas.

  • MultinomialNB: hanya menerima nilai non-negatif (cocok untuk hitungan kata atau TF-IDF). Agar bisa dipakai pada vektor Skip-gram, nilainya perlu diskalakan ke rentang 0-1 dulu. Ini dicoba sebagai pembanding di bagian 9.

Penjelasan cell berikutnya: Model GaussianNB dibuat, dilatih dengan fit() pada data latih, lalu memprediksi kelas data uji dengan predict(). Akurasi langsung ditampilkan sebagai gambaran awal.

gnb = GaussianNB()
gnb.fit(X_train, y_train)

y_pred = gnb.predict(X_test)
print(f"Akurasi data uji (GaussianNB + Skip-gram): {accuracy_score(y_test, y_pred):.4f}")

Akurasi data uji (GaussianNB + Skip-gram): 1.0000

8. Evaluasi Model#

Akurasi saja kurang lengkap, jadi dipakai beberapa metrik:

  • Precision: dari semua berita yang diprediksi suatu kelas, berapa yang benar.

  • Recall: dari semua berita yang sebenarnya suatu kelas, berapa yang berhasil ditemukan.

  • F1-score: rata-rata harmonik precision dan recall.

  • Confusion matrix: tabel benar/salah prediksi per kelas. Diagonal menunjukkan prediksi benar, di luar diagonal adalah kesalahan.

Penjelasan cell berikutnya: classification_report mencetak precision, recall, dan F1 per kelas. Setelah itu confusion matrix digambar sebagai heatmap agar mudah dibaca.

print(classification_report(y_test, y_pred, digits=4))

Validasi Silang (Stratified 5-Fold Cross-Validation)#

Penjelasan cell berikutnya: Dengan hanya 200 berita, data uji berisi sekitar 40 berita, sehingga satu kali pembagian bisa kebetulan terlalu mudah atau terlalu sulit. Cross-validation membagi data menjadi 5 bagian, lalu bergantian tiap bagian dijadikan data uji. Hasilnya dirata-ratakan sehingga estimasi performa lebih stabil. StratifiedKFold menjaga proporsi kelas di tiap lipatan, dan shuffle=True mengacak data terlebih dulu. Ditampilkan rata-rata dan simpangan baku (±) dari setiap metrik.

skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=RANDOM_STATE)

10. Klasifikasi TF-IDF + Naive Bayes (Opsi Kedua untuk Aplikasi)#

Aplikasi app.py menyediakan dua pilihan metode, sehingga selain model Skip-gram dibutuhkan satu model lagi berbasis TF-IDF:

Teks bersih jalur TF-IDF (stopword removal + stemming) -> TfidfVectorizer -> matriks TF-IDF -> MultinomialNB

  • TF-IDF bernilai non-negatif, sehingga varian yang cocok adalah MultinomialNB.

  • TfidfVectorizer harus ikut disimpan, karena ia menyimpan kosakata dan nilai IDF dari data latih yang dibutuhkan untuk mengubah berita baru. File tfidf_berita.csv tidak bisa dipakai untuk ini karena hanya berisi hasil angka.

  • Pengaturannya TfidfVectorizer() bawaan, sama seperti di preprocessing.ipynb.

Penjelasan cell berikutnya: Data dibagi 80/20 dengan parameter yang sama seperti pada Skip-gram (stratify=y, random_state=42), sehingga data ujinya identik dan perbandingan adil. Vectorizer hanya di-fit pada data latih (agar tidak ada kebocoran informasi dari data uji), lalu data uji cukup di-transform. Setelah itu model dilatih dan dievaluasi dengan akurasi, classification_report, dan confusion matrix.

teks_tfidf = df['Teks Bersih'].values      # jalur TF-IDF (stopword removal + stemming)

T_train, T_test, yt_train, yt_test = train_test_split(
    teks_tfidf, y, test_size=0.2, stratify=y, random_state=RANDOM_STATE
)

tfidf_vec = TfidfVectorizer()
Xt_train = tfidf_vec.fit_transform(T_train)   # belajar kosakata + IDF dari data latih saja
Xt_test  = tfidf_vec.transform(T_test)

mnb = MultinomialNB()
mnb.fit(Xt_train, yt_train)
yt_pred = mnb.predict(Xt_test)

print("Jumlah fitur TF-IDF (data latih):", Xt_train.shape[1])
print(f"Akurasi data uji (MultinomialNB + TF-IDF): {accuracy_score(yt_test, yt_pred):.4f}\n")

labels = sorted(set(y))

def evaluasi(nama, estimator, X_, y_):
    hasil = cross_validate(estimator, X_, y_, cv=skf, scoring=metrik)
    return {
        'Representasi + Model': nama,
        'Jumlah Fitur': X_.shape[1],
        'Accuracy': hasil['test_accuracy'].mean(),
        'Precision': hasil['test_precision_macro'].mean(),
        'Recall': hasil['test_recall_macro'].mean(),
        'F1-macro': hasil['test_f1_macro'].mean(),
    }

12. Prediksi Berita Baru#

Penjelasan cell berikutnya: Cell ini menguji kedua model pada teks berita yang belum pernah dilihat. Fungsi prediksi_berita() punya parameter metode:

  • 'skipgram': teks diproses dengan praproses_skipgram() (tanpa stopword removal dan stemming), diubah menjadi vektor dokumen dengan doc_vector(), lalu diprediksi oleh gnb_final.

  • 'tfidf': teks diproses dengan praproses_tfidf() (stopword removal dan stemming), diubah menjadi vektor TF-IDF oleh tfidf_final, lalu diprediksi oleh mnb_final.

predict_proba() menampilkan peluang tiap kelas. Jika tidak ada satu pun kata dari teks yang dikenal model, prediksi dibatalkan karena vektornya akan nol. Silakan ganti contoh teks dengan berita Anda sendiri.

Peluang dari GaussianNB cenderung terlalu percaya diri (mendekati 0 atau 1) karena asumsi independensi fitur, jadi lihat sebagai indikasi kasar saja.

def prediksi_berita(teks, metode='skipgram'):
    if metode == 'skipgram':
        tokens = praproses_skipgram(teks).split()
        if not any(t in model_sg.wv for t in tokens):
            return "Tidak dapat diprediksi: tidak ada kata yang dikenal model."
        vec = doc_vector(tokens, model_sg.wv).reshape(1, -1)
        model = gnb_final
    else:
        vec = tfidf_final.transform([praproses_tfidf(teks)])
        if vec.nnz == 0:
            return "Tidak dapat diprediksi: tidak ada kata yang dikenal model."
        model = mnb_final
    proba = model.predict_proba(vec)[0]
    kelas = model.predict(vec)[0]
    detail = ", ".join(f"{c}: {p:.1%}" for c, p in zip(model.classes_, proba))
    return f"Prediksi: {kelas}  ({detail})"

13. Kesimpulan#

Isilah kesimpulan berikut setelah semua cell dijalankan, dengan angka dari output Anda sendiri:

  1. Kualitas representasi Skip-gram. Lihat hasil most_similar dan grafik PCA 2D. Apakah kata-kata yang mirip bertema sama, dan apakah kelas SPORT dan FINANCE terpisah?

  2. Performa Naive Bayes. Sebutkan akurasi, precision, recall, dan F1 hasil cross-validation untuk GaussianNB, serta bandingkan dengan MultinomialNB.

  3. Perbandingan dengan TF-IDF dan PCA. Representasi mana yang paling baik pada tabel bagian 11? Berikan alasannya. Sebagai petunjuk: TF-IDF menyimpan kata-kata khas tiap topik secara langsung, sedangkan Skip-gram merangkum makna dan konteks kata dalam dimensi yang jauh lebih kecil.

  4. Pengaruh preprocessing. Jalur Skip-gram tidak memakai stopword removal dan stemming, sedangkan jalur TF-IDF memakainya. Jelaskan mengapa Skip-gram dibiarkan tanpa kedua langkah itu, dan apakah hasilnya berbeda dengan versi yang memakai keduanya.

  5. Keterbatasan.

    • Korpus hanya 200 berita, sehingga vektor Skip-gram belum sekuat model yang dilatih pada korpus besar.

    • Rata-rata vektor kata mengabaikan urutan kata dan bobot kepentingan kata.

    • Naive Bayes berasumsi fitur saling bebas, padahal dimensi vektor Skip-gram saling berkorelasi.

    • Dua kelas ini topiknya sangat berbeda, jadi skor tinggi belum tentu berlaku untuk kategori yang lebih mirip (misalnya finance vs bisnis).

  6. Saran pengembangan. Tambah jumlah data dan kategori, gunakan bobot TF-IDF saat merata-ratakan vektor, atau coba model pre-trained (misalnya fastText Bahasa Indonesia).
